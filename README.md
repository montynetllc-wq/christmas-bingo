# Christmas Bingo

Interactive Christmas Picture Bingo for young children on iPad and classroom Promethean boards.

## Play

Open `index.html` in a browser. The game includes its images, styles, and JavaScript within this single file, so it can also be copied and opened offline in a browser that supports local HTML files.

- Tap **Pick a Card** to reveal a Christmas picture.
- Find and tap the matching picture on the board to cover it.
- Tap the gear once to open **Teacher Settings**.
- Teacher Settings include the 4-column × 5-row and 5-column × 4-row layouts, optional voice, and Reach Mode.
- The decorative BINGO heading and original Christmas picture illustrations are included.

## Publish with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then select **Save**.
4. After Pages deploys and the custom domain in `CNAME` is set up in Pages with working DNS and HTTPS, visit [Christmas Bingo](https://christmasbingo.playtree.games/).

GitHub Pages publishing must be enabled in repository settings. A GitHub repository link is not the live game URL.

## Offline use

Download `index.html` and open it in a browser that allows JavaScript from local files. Internet access is not needed for the game's visual matching activity. Device/browser support for local HTML files and text-to-speech may vary.

## Project maintenance

This repository is the source for future game updates. Make changes to `index.html`, commit them to `main`, and GitHub Pages will publish the updated site after it is enabled.
